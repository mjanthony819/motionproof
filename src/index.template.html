MotionProof

Activity-recognition model bench: trained on real free-living sensor data, tested on people the models never saw. Everything runs in your browser.
Data: HARTH, Logacjov et al. 2021, UCI ML Repository #779, CC BY 4.0. Not a medical device: do not use for diagnosis, fall detection or monitoring people. Built with AI assistance; models trained for this project and evaluated on held-out subjects.
